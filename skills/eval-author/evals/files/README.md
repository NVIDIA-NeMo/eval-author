# Catalog assistant

This synthetic agent answers product availability questions using a read-only
catalog lookup tool. It accepts a product identifier and returns the recorded
availability, or explains that the product was not found. It cannot place orders
or change catalog records.

The agent uses a model endpoint. This documentation supplies no credentials,
execution results, evaluation cases, or confirmed Ethos.
